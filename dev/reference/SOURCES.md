# Reference data: sources

Everything the benches compare the theme against lives here. Nothing in this directory is edited by hand except this
file.

## `m3e-tokens.json`: Material 3 Expressive tokens

- Upstream: <https://github.com/androidx/androidx>, folder
  `compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/tokens/`,
  commit `41edc910b2c7cf284c302543b435bfc7d2df1e49` (androidx-main, 2026-10-02T22:23:23Z), downloaded 2026-10-03.
  License of the upstream sources: Apache License 2.0, Copyright The Android Open Source Project.
- Generated by `dev/m3e-bench/tokens.py <tokens dir> m3e-tokens.json` from the `*Tokens.kt` files of that folder
  (not vendored: download them from the commit above). The keys `ColorToken(n)`, `ShapeToken(n)`,
  `TypographyToken(n)` and `TypographyTokens` (a duplicate of `TypeScaleTokens`) are not kept.
- Schema: `{Component: {Token: {"type": ..., "value": ..., "source"?: ...}}}`. Types: `dp`, `sp`, `ms`, `role` (a
  colour role, snake case), `opacity`, `shape` (`"full"` for `CornerFull`), `corners` (four radii),
  `typography` (`value` = `{size, line_height, weight, tracking}`), `weight`, `number`, `curve`.
- Files used: ButtonLarge ButtonMedium ButtonSmall ButtonXLarge ButtonXSmall Checkbox CircularProgressIndicator
  ColorSchemeKey Dialog Elevation ExpressiveMotion FilledButton FilledIconButton FilledTextField FilledTonalButton
  FilledTonalIconButton IconButton LargeIconButton LinearProgressIndicator List MediumIconButton Menu MotionSchemeKey
  Motion NavigationDrawer NavigationRailBaselineItem NavigationRailCollapsed NavigationRailColor
  NavigationRailExpanded NavigationRailHorizontalItem NavigationRailVerticalItem OutlinedButton OutlinedIconButton
  OutlinedTextField PlainTooltip PrimaryNavigationTab ProgressIndicator RadioButton SecondaryNavigationTab ShapeKey
  Shape Slider SmallIconButton SplitButtonLarge SplitButtonMedium SplitButtonSmall SplitButtonXLarge
  SplitButtonXSmall State Switch TextButton Typeface TypeScale TypographyKey Typography XLargeIconButton
  XSmallIconButton, plus SearchBar DatePickerModal FilledCard ElevatedCard OutlinedCard FloatingToolbar
  DockedToolbar ButtonGroupSmall ConnectedButtonGroupSmall.
- Deviations from the original plan: there is no `StandardIconButtonTokens` (replaced by `IconButtonTokens` and
  `SmallIconButtonTokens` for the sizes); a single `SliderTokens`; `TypefaceTokens` added (font weights). At that
  commit there is a single button group variant (`ButtonGroupSmall`, `ConnectedButtonGroupSmall`) and two toolbars
  (`FloatingToolbar`, `DockedToolbar`).
- Sanity values checked at generation: ButtonSmall.ContainerHeight = 40, Switch.TrackHeight = 32,
  Switch.TrackWidth = 52, Checkbox.ContainerSize = 18.
- The companion repository `m3e-gnome-extensions` keeps a verbatim copy of the `ExpressiveMotion` section: re-copy it
  there after regenerating (its reader must use the `value` / `number` names above).

## `shell-stock/`: stock GNOME Shell stylesheets

- Package `gnome-shell` 50.5-1 (Debian), extracted on 2026-10-03 from
  `/usr/share/gnome-shell/gnome-shell-theme.gresource` with
  `gresource extract <file> /org/gnome/shell/theme/gnome-shell-{dark,light}.css`.
- `gnome-shell-dark.css` and `gnome-shell-light.css` (first line: a comment recording the version, added at extraction). Vendored
  unchanged otherwise: GNOME Shell is GPL-2.0-or-later (Copyright Red Hat, Inc. and contributors); these files are test fixtures
  the Shell bench compares the theme with (what the theme changes, what it leaves at stock).
- Update when the Shell version changes: re-extract both files and update the header line.
