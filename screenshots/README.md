# Screenshots

The images of the README files (`../README.md`, `../README.fr.md`) and of the
[extensions repository](https://github.com/maximeallanic/m3e-gnome-extensions). They are generated, not hand-made: a
headless GNOME Shell 50 started with `dev/screenshots/capture.sh` runs the theme (dark and light), opens real GTK 4 /
libadwaita applications (Settings, Files, Ptyxis) and the Shell surfaces, and captures the virtual 1920 x 1080 screen at
scale 1.

## Regenerate

```sh
dev/screenshots/setup.sh              # once: a venv with python-dbusmock and Pillow (needs uv)
dev/screenshots/make-screenshots.sh   # about 4 minutes; writes this directory
```

Requirements and the details of what the session fakes are in [`../dev/screenshots/README.md`](../dev/screenshots/README.md).
The nested Shell, its Wayland socket, session bus, `XDG_*` directories, system bus and audio server are all private; the
real session, home and dconf are not touched. Raw captures stay in `dev/out/screenshots/<date>/` (git-ignored, do not
publish them).

The video is regenerated with `dev/screenshots/make-video.sh` (10-15 minutes, see
[`../dev/screenshots/README.md`](../dev/screenshots/README.md)); it is recorded from the nested Shell in slow motion and retimed, with the
same demo data, procedural wallpapers and private buses as the images.

Prefer the WebP inline (GitHub renders it and loops it) and link to the MP4 for full quality; the MP4 itself cannot be
embedded with `<video>` in a README on GitHub unless it is uploaded through the web editor.

## Provenance and licence

- **Wallpapers**: generated by `dev/screenshots/wallpapers.py` (Pillow, layered gradients, fixed seeds). No third-party
  artwork. Released under **CC0 1.0**. The four pictures in the demo `Pictures` folder (Files screenshots) are the same
  images, scaled.
- **Palette**: derived from each wallpaper with the project's own `material-palette` (seed colour pinned in
  `wallpapers.SEEDS`, because the quantizer it uses is randomised).
- **Demo data**: user `demo`, a home folder with invented file names, invented Wi-Fi networks, Bluetooth devices,
  notifications, battery level. Nothing comes from a real machine.
- **Third-party artwork visible in the images**: the Papirus icon theme (GPL-3.0), Google Sans Flex (SIL OFL 1.1), Adwaita
  Mono (SIL OFL 1.1), and the GNOME applications themselves.
